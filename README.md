# RetailVision-AI — Retail Analytics Project

## 📊 Project Overview

RetailVision-AI is a retail analytics project designed to analyze **store performance, sales, customers, promotions, holidays, and competition**.

The project combines **Python, SQL, Power BI, and Streamlit** to transform raw retail data into meaningful business insights and interactive analytics.

> 🚧 **Project Status: In Progress**
>
> The current version includes data cleaning, exploratory data analysis, SQL analysis, Power BI dashboards, and a Streamlit analytics application. Machine learning and AI-based decision support are planned for the next phase.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze retail store performance
- Compare sales performance across stores
- Understand customer behavior and sales trends
- Analyze the impact of promotions on sales
- Analyze the effect of competition distance on store performance
- Study holiday and seasonal sales patterns
- Identify high- and low-performing stores
- Build interactive business intelligence dashboards
- Develop machine learning models for sales forecasting and store performance analysis
- Build an AI-powered retail decision-support layer

---

## 🗂️ Dataset

The project uses a Rossmann-style retail sales dataset containing information about:

- Store
- Date
- Sales
- Customers
- Store Type
- Assortment
- Promotions
- State Holidays
- School Holidays
- Competition Distance
- Promo2
- Competition Opening Information

The cleaned dataset contains **1M+ retail sales records**.
