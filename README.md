# RetailVision AI – Retail Analytics Project

## 📊 Project Overview

RetailVision AI is a retail analytics project designed to analyze store performance, sales, customers, promotions, and competition distance.

The project combines data preparation, SQL analysis, Power BI visualization, and an interactive Streamlit dashboard to convert raw retail data into useful business insights.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze retail store performance
- Compare sales performance across stores
- Understand the impact of promotions on sales
- Analyze the effect of competition distance on store performance
- Identify top-performing stores
- Analyze customer performance
- Create interactive business dashboards
- Generate actionable business insights from retail data
